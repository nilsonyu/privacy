# privacy

隱私權政策文件儲存庫

## 如何下載到本機資料夾 (How to Download to Your Folder)

### 方法一：克隆整個儲存庫 (Clone the repository)

```bash
git clone https://github.com/nilsonyu/privacy.git
cd privacy
```

### 方法二：下載主分支的 ZIP 檔案 (Download main branch as ZIP)

1. 訪問：https://github.com/nilsonyu/privacy
2. 點擊綠色的「Code」按鈕
3. 選擇「Download ZIP」
4. 解壓縮到您的資料夾

### 方法三：使用 Git 下載主分支 (Download main branch using Git)

```bash
# 下載主分支到當前資料夾
git clone -b main https://github.com/nilsonyu/privacy.git your-folder-name
cd your-folder-name
```
